00 — Project

01 — Sources

Upload timecoded transcripts (.srt, .vtt, .txt). Each becomes a source you can pull cuts from. If a transcript embeds its source video (or a same-named video file sits next to it), it's linked automatically.

    02 — Sequence Settings

    03 — Sequences

    Save the current cut as a named version — e.g. "Social Cut", "Broadcast Cut" — to keep more than one edit of this sequence in the same project, all sharing the same sources and media links. This names a saved version, not the sequence itself (that's "Sequence name" above).

      04 — LLM Provider

      Switch providers or models whenever you like — Generate, Revise, and every future generation in this session always use whatever's selected here at the moment you click.

      05 — Creative Brief

      Drag rows (or use ▲▼ / Alt+↑↓) to reorder, retime, edit, duplicate (⧉), or delete cuts, then apply — no need to regenerate from scratch. Use the Source/Track filter above the table to narrow a long list. Select multiple rows with the checkboxes for bulk delete or track changes. Ctrl/Cmd+Z undoes the last change to this list, including a committed timecode edit. Set a cut to "B-Roll" to lay it over the main track's audio at a specific point instead of cutting to it — an overlapping B-roll clip is flagged right on the row. Click a thumbnail to preview that cut — then use Set In/Set Out to retime it from the playhead — or use "Preview Script" to play every main cut back-to-back in order.
